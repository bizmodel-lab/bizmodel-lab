方法论卡 8-06 教材体系 · 第 8 章 商业模式

商业模式设计四步法

价值主张 → 关键资源 → 价值端 → 交付端——四步链式设计，产出可检验的商业假说。

为什么需要这张卡

很多团队"设计"商业模式的方式，是九个人围着画布九个格子同时开填——填完格子各自矛盾，主张撑不起资源，收入配不上成本。教材指出，商业模式设计可分解为四个递进步骤，且每一步的输出构成下一步的输入，形成从"为何存在"到"如何运转"的完整逻辑链。

四步法的价值不在"多一步"，而在顺序：先定主张再盘资源，先铺价值端再搭交付端，每一步都踩着上一步的产出走。它带来三层实践价值：

链式防跳跃
主张未定就谈资源、资源未清就铺渠道——四步链条锁死这类越级设计。
资源先行校验
第二步强制盘点"手中鸟"资源，让主张落进现实约束，防空中楼阁。
产出可检验
四步走完得到的是明确标注为"假说"的方案，直接衔接验证流程。
四步法背后的设计准则（教材列有五项）：价值中心、系统协同、资源适配、假设驱动——"任何新设计的商业模式，都只是一个未经证实的假设集合"、动态演化。

逐步详解

第一步

定义核心价值主张

回答：客户为何选择你？
主张是整个模式的"北极星"——后面三步全部围绕它展开。
核心动作
写出经过初步验证的价值主张草稿：不是完美文稿，而是"为谁、解决什么核心问题、提供什么独特价值"的初稿。
为何先行
主张未定就设计资源与渠道，等于不知道目的地先买机票；主张虽是草稿，也须先过初步验证，不能纯凭想象（深化操作见卡 8-07）。
本步产出
一句经得起追问的价值主张草稿，作为第二步盘资源的参照系。
第二步

盘点关键资源

审视："手中鸟"资源
先看清手里有什么，再决定模式能做多大。
核心动作
把手头资源分成三类：可直接利用 / 需获取 / 需创造性拼凑。专利技术、行业专长、渠道关系、初始用户群、个人声誉，都是候选清单项。
为何紧随主张
用第一步的主张当筛子：资源盘点不是罗列家底，而是追问"这些资源如何帮我实现这个主张？"对不上的资源再多也是闲子。
本步产出
一张带分类的资源清单 + 资源缺口初判（难以获取的缺口，反过来可能要求调整主张）。
第三步

展开价值端设计

范围：细分 / 渠道 / 关系 / 收入
把主张翻译成面向市场的四个模块。
核心动作
依次设计客户细分、渠道通路、客户关系、收入来源四个模块，使其市场策略化——每格都直接服务第一步的主张、用得上第二步的资源。
操作要点
细分用递进式策略（先极端用户后扩大），主张按三层面递进到用户利益，收入警惕单一模式——判定规则详见卡 8-02。
本步产出
价值端四模块方案：卖给谁、怎么触达、处成什么关系、怎么收钱。
第四步

搭建交付端架构

范围：资源 / 业务 / 伙伴 / 成本
把"怎么送达"变成"怎么做出来"。
核心动作
搭建核心资源、关键业务、合作伙伴、成本结构四个模块，让价值端的每个承诺背后都有交付能力支撑。
操作要点
"缺失即停摆"的资源优先内部构建，非核心业务外包，合作伙伴按资产专用性定治理机制，成本引入单位经济视角（详见卡 8-02 交付端规则）。
本步产出
九模块齐备、逻辑自洽的完整商业模式方案。
收尾判定：四步走完，你手里是一份逻辑自洽的方案，但教材紧接着提醒——"它仍然是一个有待检验的商业假说，必须通过市场验证来迭代修正。"设计结束之时，就是验证开始之日。

怎么用这张卡

  1. 写主张。用一句话写出价值主张草稿并做初步验证（访谈几个目标客户），暂不追求完美——它会在后续步骤中被修正。
  2. 盘资源。列资源清单并分三类：可直接利用 / 需获取 / 需创造性拼凑；对照主张问"它能帮我实现主张吗"。
  3. 查缺口。识别关键资源缺口，评估获取难度与成本——难以获取的缺口，回头修订主张而不是硬上。
  4. 铺价值端。依次定客户细分、渠道、关系、收入四模块，每格标注它如何服务主张、动用哪项资源。
  5. 搭交付端。定核心资源、关键业务、合作伙伴、成本结构，确保价值端的每个承诺都有交付支撑。
  6. 整体自检。用教材系统协同原则的三个检验过一遍：主张—细分匹配、收入—成本平衡、业务—资源呼应。
  7. 送验证。把方案当作假说交给验证流程：MVS 三闭环（卡 8-13）+ 四种系统测试（卡 8-14），用证据迭代修正。

适用场景与边界

适用

  • 从 0 到 1 的商业模式首构：第一次把想法变成完整方案
  • 新业务线 / 第二曲线设计：在公司内套用同一套链式逻辑
  • 写商业计划前的骨架梳理：先有自洽的四步方案，再写文档
  • 团队共创的结构化流程：四步即四次工作坊的天然议程

慎用与注意

  • 四步是逻辑顺序而非单行道，允许回改，但不可跳步——尤其不能跳过第二步直接铺渠道
  • 第一步的主张未经初步验证就往下走，后面三步全是空中楼阁
  • 产出物不等于事实：逻辑自洽只是及格线，市场验证才是终审（卡 8-13、卡 8-14）
