谷子经济

"谷子"＝Goods（商品）的音译，指二次元 IP 周边商品——围绕它的情绪消费，正从小众圈层长成千亿级新赛道。

概念界定

谷 子

IP 周边商品本身

以动漫、漫画、游戏、小说、虚拟偶像等 IP 为核心的周边商品。
  • 品类：徽章（"吧唧"）、亚克力立牌、卡牌、挂件、手办等
  • 圈层用语："吃谷"＝购买，"谷店"＝售卖场所
  • 特征：单价较低、购买高频，属仪式性微消费
谷子经济

围绕谷子的消费生态

围绕二次元 IP 周边商品形成的消费经济形态，本质是情绪经济与符号消费的深度融合。
  • 产业链完整：上游 IP 开发运营、中游设计生产、下游市场销售
  • 消费群体以女性为主，一线城市消费者占半数以上
  • 国产 IP（《原神》《第五人格》等头部游戏 IP）加速占据市场核心

谷子消费的三重动因与循环链路

理论源流

谷子消费的本质，是情绪经济与符号消费的深度融合。 —— 教材知识链接 11-3

三重递进的内在动因：其一，情感联结——Z 世代伴随二次元文化成长，与 IP 虚拟角色形成长期情感投射，谷子成为承载情感记忆的纪念品；其二，身份认同——把徽章等周边装饰在"痛包"（itabag）上随身携带，实现喜好外化、自我表达与圈层识别；其三，社交互动——在社交媒体"晒谷"，形成"消费—展示—互动—再消费"的循环链路。消费行为因此被概括为"花小钱、表态度、重展示、融圈子"。

辨析要点

  1. 卖的不是商品，是情绪与符号：谷子的溢价来自 IP 情感与圈层认同，而非使用价值——用普通消费品逻辑定价会失焦。
  2. 圈层逻辑优先于大众逻辑：产品设计、话术与渠道都要进入圈层话语体系（吧唧、痛包、晒谷），否则难以获得认同。
  3. 产业链站位决定打法：上游拼 IP 开发运营能力，中游拼设计与生产效率，下游拼渠道与社群运营。
  4. IP 来源正在结构性变化：国产 IP 加速占据市场核心，头部游戏 IP 带动周边热销——选品需盯住 IP 生命周期。
资本观察：资本正加速涌入数字文化领域，数字科技与文化产业深度融合的赛道备受青睐；IP 衍生品、潮玩、短剧等领域的头部企业纷纷通过上市或融资加速发展——谷子经济正是 IP 经济持续升温的缩影。

使用建议

适用场景

  • 先定产业链站位：做 IP 开发、设计生产还是渠道销售，能力模型完全不同
  • 用"消费—展示—互动—再消费"的循环设计社群运营与产品迭代节奏
  • 围绕国产头部 IP 与长青 IP 布局选品，兼顾热度与生命周期

注意边界

  • IP 授权合规是底线：无授权周边的法律与平台风险极高
  • 情绪消费有热度周期：IP 过气即库存，需控制囤货与 SKU 风险
